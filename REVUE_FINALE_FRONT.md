# Revue finale du frontend Chantial

- Dashboard bailleur restructuré : chargement robuste, état vide, synthèse chantier, budget, dépenses, solde, avancement, anomalies, demandes et recommandations.
- Les données du dashboard restent issues des API existantes ; aucune donnée métier de démonstration n'a été ajoutée.
- Accès directs depuis le dashboard vers Ma construction et le contrôle des justificatifs.
- Landing page améliorée : navigation interne fonctionnelle, proposition de valeur clarifiée, OCR/RAG expliqués sans surpromesse, CTA cohérents, suppression des liens vers des routes inexistantes.
- Textes marketing corrigés : suppression des formulations « justificatifs infalsifiables » et des promesses de validation automatique.
- Les interfaces entrepreneur existantes et les six services métier ont été conservés.

À valider sur la machine de développement : `npm install` puis `ng build`.
